# Governance

Justin Hart is the GSIP product owner and final decision-maker during the
bootstrap phase. Changes land through protected pull requests after automated
checks, independent adversarial review, one non-author GitHub approval, and the
product owner's go/no-go.

Architecture changes require a specification update before implementation.
Privacy invariants I5 and I7 are reviewed on every pull request. As the external
maintainer community grows, the project will document a steering-group process
and transfer routine decisions to that group.
