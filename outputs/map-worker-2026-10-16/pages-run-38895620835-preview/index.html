A shared visual standard

One card. Any modern phone.

The free reference card gives every image a common scale, exposure target, marker, and color reference. It helps check the image; it does not turn a phone into a spectrometer. Extracted soil RGB remains uncalibrated.

Privacy by architecture

Sharing evidence starts with protecting the person behind it.

01

Precise stays private

Exact coordinates support enrichment and QA inside protected infrastructure only.

02

Metadata is stripped

The pipeline sanitizes embedded metadata. Photo publication stays held until screening is deployed and its calibration approved.

03

Uncertainty is explicit

Public soil maps are priors, not truth. Future estimates must show their basis and confidence.

Built in the open

The whole stack is open source.

The apps, backend, data pipeline, library tools, modelling code, API and reference-card generator are available in the public repository. Fork, run, modify and extend the MIT-licensed software, or build on one part of it.

Run a private local library node with the public source. Your records and credentials remain protected. These tools do not register a node for GSIP’s hosted service; public uploads stay closed. We welcome developers, soil scientists and spectroscopy labs to help build verified paired evidence and future open models.
