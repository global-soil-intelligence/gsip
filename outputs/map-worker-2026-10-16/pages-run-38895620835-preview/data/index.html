Pre-publication

Public data releases remain gated.

The release job fails closed if a contribution lacks its immutable grant, contains a precise location field, or carries embedded image metadata. New releases contain structured data only until photo screening is deployed and its calibration approved.

Individual spectra remain private pending a fingerprinting and privacy review, even without coordinates. An H3 cell alone does not make a spectrum safe to publish.

Public release boundary

Useful fields in. Sensitive fields out.

Eligible structured release fields

  • k-anonymous H3 cells (resolution 8, 6 or 4)
  • Date-truncated capture time
  • Protocol context and per-photo QA checks
  • Verified, rights-eligible labels outside sealed holdouts
  • Provenance tier and published licence terms

Never public

  • Precise geometry or GPS accuracy
  • Point-level soil-map priors, which pinpoint location
  • Contributor or grant identifiers
  • Device model or private camera fields
  • Raw uploads or embedded metadata
  • Private worker and queue state

Citation and takedown

Publication must be traceable. Withdrawal has limits.

The generated dataset card carries source citations, schema, license boundaries, photo attribution, and export-date provenance. A public privacy contact will be published before real contributions are released. Copies already released may persist; withdrawal removes eligibility from future GSIP releases and requires affected artifacts to be rebuilt. Do not post private contributor details in public issues.

Build on the library

Start locally. Keep evidence and authority separate.

The private local store accepts typed camera RGB and instrument reflectance records linked by sample identity. Local declarations are not verified GSIP acceptance. Hosted uploads, node exchange and public spectral releases remain gated.
