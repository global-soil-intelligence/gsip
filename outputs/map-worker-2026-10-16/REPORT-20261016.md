## Changes and why

- Bundle MapLibre's existing worker and dependencies with Vite, then configure its URL before constructing the map. Vite did not discover MapLibre's dynamic sibling worker URL in the old build, causing a missing resource.
- Ship full upstream dependency notices with the map. Independent review identified that the emitted worker needed its accompanying existing licence text; no project licence or dependency changed.
- Add a unit check for worker configuration order and a real browser regression using the emitted worker at both the repository subpath and custom-domain root. The tests fail before the repair and pass afterward, including actual synthetic H3 feature processing.
- Add a root-map route to the loopback-only test handler and test its path guards. Production capture fixtures are never added to Pages.
- Register WP-SITE-1G and its invariants/acceptance in BUILD_ORDER. No architecture, schema, service, permission or privacy policy changes.
