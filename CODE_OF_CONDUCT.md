# Code of Conduct

GSIP contributors must help maintain an open, respectful, harassment-free
community. Be considerate, critique ideas and code rather than people, respect
privacy, and assume good intent while remaining precise about safety.

Unacceptable conduct includes harassment, threats, discriminatory language,
publishing another person's private information, sexualized attention, or
disruption intended to make collaboration unsafe.

Project maintainers may remove content, restrict participation, or ban a
participant when necessary to protect the community. Report incidents privately
to the project owner. Reports will be handled as confidentially as practical.

This policy applies in project repositories, discussions, events, and any public
space where a participant represents GSIP.
